# Cybersecurity Internship Projects

## Overview

This repository contains project documentation, testing evidence, screenshots, and a consolidated report prepared as part of a cybersecurity internship.

The repository is organized to make the project work and supporting evidence easy to review.

## Projects

1. **Network Reconnaissance and Service Enumeration**  
   Documentation of authorized network reconnaissance and service enumeration activities.

2. **Hidden Directory and File Enumeration**  
   Documentation of web directory and file discovery tests.

3. **Login Traffic Analysis**  
   Analysis of captured login-related network traffic and the observations supported by the available evidence.

4. **Basic Web Vulnerability Assessment**  
   Documentation of web application security checks and relevant findings.

5. **OWASP Juice Shop Security Assessment**  
   Documentation of testing activities, observations, supporting evidence, and remediation recommendations.

6. **PortSwigger Web Security Academy Labs**  
   Documentation of the web security labs completed, with supporting evidence.

## Repository Contents

- Individual project folders
- Screenshots and supporting evidence
- Project notes and documentation
- Consolidated internship report

## Tools and Platforms

Tools and platforms used are documented within the corresponding project folders and report.

## Evidence and Reporting

Findings should be interpreted in the context of the recorded tests and available evidence. Unconfirmed observations are not presented as verified vulnerabilities.

## Disclaimer

This repository is intended for educational and authorized cybersecurity testing. All testing should be performed only in environments for which permission has been granted.
