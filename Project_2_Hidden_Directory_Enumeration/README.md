# Hidden Directory & File Enumeration

## Project Information

- Organization: CyberSNova
- Domain: Cyber Security
- Level: Beginner
- Project Number: 2
- Target: http://testasp.vulnweb.com/
- Operating System: Kali Linux

## Objective

Perform authorized web directory and file enumeration using
Gobuster, Dirsearch, and Dirb. Record the actual responses,
review interesting paths, and document potential security risks
supported by the collected evidence.

## Tools

- Gobuster
- Dirsearch
- Dirb
- curl
- SecLists wordlist

## Project Structure

- report/: Project report
- results/: Tool output and findings
- screenshots/: Genuine screenshots of execution and results
- evidence/: Environment details and supporting evidence

## Results

Results are stored in the results directory. Consult the

read-only requests described in this project. No fabricated
