# OWASP Juice Shop Security Assessment

Domain: Cyber Security
Level: Intermediate
Project Number: 1
Target: https://demo.owasp-juice.shop/

## Objective
Assess the intentionally vulnerable OWASP Juice Shop training
application, document at least five distinct vulnerabilities,
collect genuine evidence, and recommend mitigations.

## Contents
report/      Report draft and final report
screenshots/ Genuine screenshots of testing and results
evidence/    Sanitized supporting evidence
notes/       Testing notes and findings register

## Evidence policy
Record only findings verified during testing.
Do not fabricate screenshots, responses, or results.
Redact credentials, tokens, and personal information.
